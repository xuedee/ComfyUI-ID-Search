# ComfyUI IDSearch Pro (Ultimate Edition)

A powerful node navigation and semantic search system for ComfyUI.

## 🚀 Key Features
- **Search Anything**: Search by ID, Title, Type, or even Widget content (Prompts, LoRAs).
- **Smart Navigation**: `X + D + ⬅️/➡️` to traverse the graph logically.
- **Branch Awareness**: Automatically detects multiple connections and allows cycling through them.
- **Relocate Anchor**: Press `X + D + V` to quickly jump to any node and reset your navigation path.
- **Non-Destructive**: Temporary highlights are automatically cleared before saving.

## ⌨️ Shortcuts
- `X + D + F`: Focus/Wake up the search bar.
- `X + D + V`: Relocate/Reset the start node (Anchor).
- `X + D + ⬅️/➡️`: Logical navigation through the workflow.
- `▼`: Click the triangle to view search history.
